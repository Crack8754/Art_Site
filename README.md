# Artas

Artas — головна сторінка візуальної платформи для митців і поціновувачів мистецтва. Концепція натхненна стрічкою Pinterest: відвідувачі можуть відкривати роботи, зберігати їх та переходити до публікації власного арту.

## Можливості

- Адаптивна головна сторінка українською мовою.
- Hero-секція з ключовою цінністю платформи та статистикою.
- Галерея рекомендованих робіт із категоріями.
- Кнопки збереження робіт, пошук та модальне вікно публікації.
- Вбудований Node.js HTTP-сервер без зовнішніх залежностей.

## Технології

- HTML5
- CSS3 (адаптивність, анімації, CSS Grid)
- Vanilla JavaScript
- Node.js (вбудований модуль `http`)

## Запуск локально

Потрібен Node.js 18 або новіший.

```bash
npm start
```

Після запуску відкрийте [http://localhost:3000](http://localhost:3000) у браузері.
